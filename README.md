# Docsy – AI-Powered Document Generation

Docsy is an AI-powered platform that helps students and professionals generate fully formatted reports, research papers, and documentation in minutes.

## Features

- AI-generated reports
- Smart document templates
- Automatic formatting
- Citation generation
- Export to PDF / DOCX

## Tech Stack

This project is built using:

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
